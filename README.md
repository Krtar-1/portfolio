## Carter Glidewell Portfolio

## Description
This is a personal portfolio website built with React.js to showcase my skills, projects, and experience.

## Features
- Multi-page navigation using React Router
- Responsive design for desktop and mobile
- Project showcase with links
- Contact form with validation
- Animations using Framer Motion

## Technologies Used
- React
- Vite
- JavaScript
- HTML & CSS
- React Router
- Framer Motion

## Setup
npm install  
npm run dev  

## Deployment
Deployed using GitHub Pages
